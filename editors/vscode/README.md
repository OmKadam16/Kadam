# Kadam for VS Code

Language support for [Kadam](https://github.com/OmKadam16/Kadam) `.kdm` files:

- syntax highlighting;
- the same errors and warnings as `kadam check`, as you type;
- completion of every Kadam sentence and of your project's components;
- hover documentation for the sentence under the cursor and for error codes;
- go to definition for components, pages, states and elements;
- formatting, the same as `kadam format`.

The language features come from `kadam lsp`, so the `kadam` command must be
installed. If it is not on your `PATH`, set **Kadam: Path** (`kadam.path`).
